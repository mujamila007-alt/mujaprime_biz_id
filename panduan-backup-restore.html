Catatan keamanan penting

Jangan pernah membagikan kode OTP, kode verifikasi, PIN, atau sandi kepada siapa pun. Muja Prime tidak meminta kode rahasia akun. Admin hanya boleh memandu langkah aman yang Anda jalankan sendiri di perangkat Anda.

Yang dibantu admin

Menjelaskan persiapan data, file, dan aplikasi pendukung yang diperlukan.
Memandu proses backup dan restore secara bertahap.
Membantu pengecekan jika ada langkah yang gagal atau file tidak terbaca.

Yang perlu dilakukan user

Menyiapkan perangkat, koneksi stabil, ruang penyimpanan, dan file akun milik sendiri.
Tidak membagikan OTP, sandi, PIN, atau data rahasia akun kepada siapa pun.
Mengikuti instruksi admin dan memastikan akun yang diproses adalah milik sendiri.

Alur kerja layanan

Baca urutan ini sebelum membeli agar Anda tahu proses dari awal sampai selesai.

1
Pilih produk

Buka koleksi, baca halaman panduan, lalu pilih paket yang sesuai.

2
Login akun situs

Gunakan data akun Muja Prime agar order dan poin tercatat.

3
Bayar & upload bukti

Pilih metode pembayaran lalu kirim bukti pembayaran di halaman payment.

4
Verifikasi admin

Admin memeriksa pembayaran dan mengarahkan ke status layanan.

5
Persiapan file

Admin memberi daftar persiapan dan aplikasi pendukung yang perlu dipakai.

6
Pendampingan restore

Admin memandu langkah restore secara aman melalui chat.

7
Pengecekan hasil

Pastikan data terbaca, file masuk, dan aplikasi berjalan sesuai kondisi perangkat.

8
Selesai

Jika gagal karena tidak kompatibel, gunakan garansi sesuai ketentuan.

Garansi & refund

Jika setelah dicek proses memang tidak kompatibel atau gagal total karena kondisi teknis, pelanggan berhak mengikuti garansi/refund sesuai paket dan kesepakatan pembelian. Garansi tidak berlaku untuk penyalahgunaan akun, akun bukan milik sendiri, atau permintaan melewati keamanan/verifikasi platform.
